# Валідація форми

## Поле Employee
Переконайтеся, що поле `employee` заповнено.  
Використовуйте метод валідації для поля `clean_<field_name>` для цього.  
Виведіть відповідну помилку, якщо робітник не буде вибраний.

![Поле Employee](image-2.png)

## Лікарняні дні
Перевірте, що кількість лікарняних днів не перевищує **5**.  
Для цього використовуйте метод `clean()` форми. Не забувайте використовувати `super()`, щоб застосовувались вже вбудовані перевірки.  

1. Порахуйте кількість лікарняних днів.  
2. Якщо їх більше 5, зарейзте `forms.ValidationError("message_text")`, де в повідомленні напишіть відповідний текст помилки.
